# Customer lifetime value training data

`raw/customer_data.csv` is the original source dataset. The training pipeline
does not overwrite it.

`raw/customer_data_ngn.csv` is a reproducible, synthetic dataset generated by
`generate_synthetic_data.py` using seed `20261004`. It contains 1,000 example
customers and represents monetary amounts in Nigerian naira (₦). It is not
observed Nigerian customer data. `processed/customer_data_processed.csv` is
derived from this synthetic file and is the dataset used by `train_model.py`.

## Input ranges

| Field | Generated range |
| --- | ---: |
| Annual income | ₦500,000–₦20,000,000 |
| Average order value | ₦5,000–₦400,000 |
| Purchases per year | 1–25 |
| Products purchased | 1–50 |
| Satisfaction score | 1.0–5.0 |

The prediction form uses the observed minimum and maximum values in the
processed training data and rejects numeric inputs outside those limits.

## Synthetic CLV formula

Purchases per year is treated as an annual count. The generated
`CustomerLifetimeValue` is estimated lifetime gross revenue, not profit:

```text
tenure_years = max(
    0.6,
    churn_base_years
    + membership_tenure_bonus
    + 0.12 * (satisfaction_score - 3)
    + Normal(0, 0.12)
)

product_breadth_factor = 0.9 + 0.1 * products_purchased / 50
discount_realization_factor = 0.97 if a discount was used, otherwise 1.0
customer_variation = clip(Normal(1.0, 0.04), 0.85, 1.15)

CLV = round(
    average_order_value
    * purchases_per_year
    * tenure_years
    * product_breadth_factor
    * discount_realization_factor
    * customer_variation
)
```

The churn-based tenure assumptions are 4.75 years for low risk, 2.75 years for
medium risk, and 1.25 years for high risk. Membership adds 0 years for Bronze,
0.25 for Silver, 0.5 for Gold, and 0.75 for Platinum. The generator's seeded
random variation makes this a reproducible teaching dataset, not a validated
customer-lifetime or accounting model. Income and demographics do not directly
enter the target formula.

## Regenerate and train

From the project root, run:

```text
python generate_synthetic_data.py
python transform_data.py
python train_model.py
```

Training evaluates a held-out 20% split (random seed 42) and selects the model
with the best R² on that synthetic test split. Test metrics describe fit to the
synthetic formula and should not be presented as validation on real customers.
